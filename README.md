### 1. Prasyarat
- Node.js 18+ → https://nodejs.org
- Akun Google (untuk Gemini API gratis)

### 2. Dapatkan Gemini API Key
1. Buka https://aistudio.google.com/app/apikey
2. Login Google → Klik "Create API Key"
3. Copy key (format: `AIzaSy...`)
